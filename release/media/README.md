# Listing media

Generated by [`scripts/make-listing-media.py`](../scripts/make-listing-media.py) — Pillow for the
images, `imageio-ffmpeg` for the video. Rebuild with:

```sh
python3 -m pip install --user --break-system-packages pillow imageio-ffmpeg
python3 scripts/make-listing-media.py
```

| File | Size | Purpose |
|---|---|---|
| `aurix-hero-1920x1080.png` | 1920×1080 | Hero / social card: brand, headline, five capabilities, Store + web links, version |
| `aurix-hero-1080x1080.png` | 1080×1080 | Square crop for square slots |
| `aurix-walkthrough.mp4` | 1280×720, 28.5 s, silent, H.264 yuv420p, faststart, ~320 KB | Six-card walkthrough: what the app is, images, writing + code, PDF chat and library, where to get it, honest limits |
| `aurix-walkthrough.vtt` | — | English captions for the video |

**These are brand illustrations, not screenshots.** No interface is drawn that the app does not
have, nothing claims a feature the build lacks, and no screenshot is simulated. If a Store slot
requires an actual screenshot of the running Windows app, capture it on Windows with
[`scripts/capture-windows-store-screenshots.ps1`](../scripts/capture-windows-store-screenshots.ps1).

The English listing text that pairs with these files is [`LISTING-EN.md`](../LISTING-EN.md).
