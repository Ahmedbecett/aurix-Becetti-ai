Last updated: October 24, 2026. AURIX requires Google sign-in for its interactive studio on Firebase Hosting; its static informational pages remain public. This policy describes the current implementation only.

Generations

Your signed-in browser sends generation requests to the AURIX Cloudflare Worker. Image prompts are processed by Cloudflare Workers AI using FLUX.1 Schnell (Black Forest Labs); text and code prompts go to Pollinations.ai Classic endpoints. For chat, only messages and locally extracted text from a user-selected PDF are forwarded by the Worker to Google Gemini when a verified free-tier Gemini key is configured. The original PDF file stays on the device. Free-tier Gemini data may be used to improve Google products; these providers may log requests. Do not enter confidential information or credentials. Its own privacy policy governs its processing.

Local storage

Prompts, recent chat messages, generated text, legacy image links, favorites, folders and language preference are stored in your browser. Newly generated image bytes are saved locally in IndexedDB under the signed-in account and are not included in JSON export or cloud Firestore. Clear or export the data from the application's Settings. Local projects are scoped to your Google account on this browser and are not automatically synced to other devices.

Hosting and other services

Firebase Hosting (Google) hosts this staging site and may use cookies or collect technical data under its own terms. Cloudflare processes signed-in API requests and image generation through Workers AI; Google Gemini processes chat messages and extracted PDF text when chat is configured. This version does not enable an independent ad network or analytics service. Google sign-in uses Firebase Authentication and text and code projects you explicitly save to cloud are stored in Firestore under your user ID; new image bytes are local only. Refer to Google Privacy Policy and Pollinations.ai privacy information for provider practices.

Data requests

Google sign-in is processed by Firebase Authentication. Explicit cloud project copies are stored in Cloud Firestore; delete your account and cloud items in Settings. Clearing the browser's local data removes locally saved projects here; it does not remove provider logs. Contact the provider about its own data retention and deletion.
