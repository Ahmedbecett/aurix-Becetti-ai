# AURIX — لوحة تحكم مستوحاة من الصورة المرجعية

## ما تغيّر
- تصميم داخلي كحلي داكن وبنفسجي/أزرق نيون ولمسات برتقالية، لوحة Dashboard ببطاقات متجاوبة مع الهاتف وRTL العربية/الفرنسية/الإنجليزية.
- إحصاءات حقيقية **محلية لهذا الحساب وهذا المتصفح**: الصور المحفوظة، نتائج الشيفرة، ردود الدردشة الحديثة، والمشاريع المحلية. لا أرقام مثال ولا نتائج مختلقة.
- نشاط ومشاريع حديثة من البيانات الفعلية، مع حالة Google sign-in من الجلسة، وفحص حي لصحة AURIX API من `/health`؛ عدم نجاح الفحص يظهر «غير متاح» ولا يستنتج منه حالة Gemini أو فيديو أو خدمات أخرى.
- رابط محادثة PDF يستخدم الأداة القائمة: الأصل يبقى على الجهاز؛ النص المستخرج فقط يرسل عند السؤال. صفحة Usage & limits تشرح أن الفوترة والخطط المدفوعة والعداد الحي غير متاحة، والفيديو غير مفعّل. لا بطاقة Upgrade وهمية ولا ادعاء ربط Brevo أو Vercel.
- شعار الجمجمة المضمّن في النسخة المنشورة **لم يُغيّر**؛ تتحرك صورته برفق بـCSS مع وهج ومدار، ويتوقف التحريك عند تفعيل تقليل الحركة في الجهاز.
- القوائم منظمة: Dashboard، الأدوات، المشاريع والنشاط، الإعدادات والاستخدام، المعلومات. نموذج تسجيل Google وحماية الأدوات كما كانا. ملفات Search Console و`ads.txt` والخرائط والصفحات العامة بقيت محفوظة؛ لا سكربت إعلانات.

هذه حزمة Hosting فقط، والملف `AURIX-dashboard-preview.html` معاينة تصميم بحساب فارغ تجريبي **وليست الموقع الحي أو إثبات اتصال الخدمات**. استُعيدت ملفات Hosting العامة من النسخة المنشورة، لأن تنزيل ZIP المشروع الكامل من Drive عبر الموصل فشل في هذه الجلسة؛ لذلك `src/live-base.*` ليس نسخة المطور الأصلية بل مقتطفات CSS/JS من النشر الحي. احتفظ بأرشيف `aurix-2026-10-24.zip` في Drive كما هو.

## النشر من الهاتف

ارفع `AURIX-dashboard-update.zip` إلى Google Cloud Shell ثم نفذ:

```sh
cd ~ && unzip -o AURIX-dashboard-update.zip && cd AURIX-dashboard-update && bash deploy.sh
```

اكتب `yes` للتأكيد. بعد النشر افتح `https://aurix-ea09b.web.app/` وسجّل الدخول بـGoogle لرؤية الواجهة. إن بقيت نسخة قديمة افتح نافذة خاصة. لا ترسل مفتاح Admin أو كلمات مرور.
