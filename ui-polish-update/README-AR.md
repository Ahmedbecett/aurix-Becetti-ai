# تحسين تصميم AURIX الداخلي

- الشعار: AURIX فوق الجمجمة وAI تحتها، باستخدام رسم الجمجمة الأصلي.
- استبدال رموز القائمة الجانبية بأيقونات SVG موحدة ومحاذاة ثابتة؛ بطاقات الأدوات متناسقة وتتكيّف مع الهاتف وRTL.
- إصلاح غياب صورة الشعار في الصفحة الداخلية بعد تسجيل الدخول، وتنظيم مساحة العرض الرئيسية.
- لا تغيير لخدمات الذكاء الاصطناعي أو تسجيل Google أو بوابة الأدوات. `ads.txt` وخرائط الموقع وملف Google للتحقق محفوظة. لا كود إعلانات.

يمكن مشاهدة `AURIX-internal-preview.html` محليًا لتصور التصميم فقط؛ المعاينة غير متصلة بالخدمات وليست طريقة لتجاوز تسجيل الدخول في الموقع الحقيقي.

**الحزمة جاهزة ولم تُنشر من بيئة العمل.** ارفع `AURIX-visual-update.zip` إلى Cloud Shell من الهاتف، ثم نفّذ:

```sh
cd ~ && unzip -o AURIX-visual-update.zip && cd AURIX-visual-update && bash deploy.sh
```

اكتب `yes` لتأكيد نشر Firebase Hosting لمشروع `aurix-ea09b` فقط. بعد النشر افتح `https://aurix-ea09b.web.app/`؛ تسجيل Google مطلوب للدخول إلى الواجهة الداخلية. إذا ظل الشكل القديم، حدّث الصفحة تحديثًا قويًا أو افتحها في نافذة خاصة ثم سجّل الدخول.
