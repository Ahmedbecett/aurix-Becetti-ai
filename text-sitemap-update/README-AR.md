# AURIX: تجربة خريطة نصية مستقلة

هذه الحزمة **لم تُنشر من بيئة العمل**. `sitemap.txt` جديد يحتوي نفس الروابط العامة الثمانية في `sitemap.xml` المنشورة. ملفات الموقع العامة الأصلية مضمنة حتى لا يحذف نشر Firebase أي صفحة أو أصل. الخريطة XML و`robots.txt` لم يتغيرا؛ لا تعدّل أو تحذف الإدخال القديم الآن. التجربة لا تضمن قبول Google أو الفهرسة.

من الهاتف، ارفع `AURIX-text-sitemap-test.zip` إلى Google Cloud Shell، ثم نفّذ الأمر التالي:

```sh
cd ~ && unzip -o AURIX-text-sitemap-test.zip && cd AURIX-text-sitemap-test && bash deploy.sh
```

اكتب `yes` حين يطلب السكربت التأكيد. **لا تُرسل `sitemap.txt` إلى Search Console قبل نجاح النشر** وظهور الروابط الثمانية عند فتح:

`https://aurix-ea09b.web.app/sitemap.txt`

ثم في خاصية Search Console `https://aurix-ea09b.web.app/` افتح **خرائط الموقع → إضافة خريطة موقع جديدة** وأدخل `sitemap.txt` فقط، مرة واحدة، وأرسل صورة حالة الخريطة الجديدة. إذا نجحت النصية وفشلت XML نستطيع عزل مشكلة معالجة XML/مدخلها؛ إذا فشلتا معًا نتجه إلى تشخيص الجلب/التقرير بدل تغيير XML عشوائيًا. لا تُعد إرسال الخريطة القديمة الآن.
